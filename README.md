# GCC Compass by Flexiple

> **The Single Source of Truth & Operating System for India's Global Capability Centres (GCCs)**  
> Built for the Flexiple Product Intern Assignment (October 2026).

---

## 🌟 Executive Summary

India is home to **2,000+ Global Capability Centres (GCCs)** employing **1.65M+ professionals** and generating **$64.6B+ in annual tech exports**. By 2030, this ecosystem expands to **2,500+ centres** and **$100B+** in economic output. 

Yet setting up in India is plagued by crippling information asymmetry:
* Global entrants lose **6 to 9 months** and pay **$150k–$300k** in traditional advisory retainers.
* Experience **30%+ Year-1 attrition** due to outdated compensation data.
* Miss out on **₹5–25 Cr** in unclaimed state government capital subsidies and stamp duty waivers.
* Rely on subjective WhatsApp whisper networks and 18-month-old PDF surveys.

**GCC Compass** provides the verified intelligence, city benchmark comparator, dynamic setup feasibility simulator, and verified partner network that turns months of confusion into days of clarity—while funneling high-intent enterprise demand directly into **Flexiple's premier tech talent and engineering solutions**.

## 🚀 Quick Start: Running the Interactive Prototype

The prototype is a fully functioning modern web application built with **React 18**, **Tailwind CSS**, and **Vite**.

### 1. Install Dependencies & Start the Dev Server
```bash
npm install
npm run dev
```

### 2. Open in Browser
Visit **`http://localhost:3000`** in your browser.

## 📂 Project Structure & Deliverables

* **`GCC_STRATEGY_DECK.md`**: Complete, comprehensive strategy document covering the Problem, Opportunities, Solution, Positioning, ICP, Business Model, and Roadmap.
* **`deck.html`**: Standalone, interactive HTML presentation deck that can be opened directly in any web browser without running a local server.
* **`src/components/DeckViewer.jsx`**: In-app interactive 10-slide presentation deck with keyboard navigation (`←`/`→`), speaker notes, and live prototype jump links.
* **`src/components/GccDirectory.jsx`**: Filterable directory of 2,000+ GCCs (searchable by sector, city, headcount tier, tech stack) with deep modal dossiers.
* **`src/components/CityComparator.jsx`**: Head-to-head benchmarking across Bengaluru, Hyderabad, Pune, Chennai, Delhi NCR, Coimbatore, and Kochi with state IT policies (e.g. Karnataka GCC Policy 2024–2029 ₹25 Cr subsidies).
* **`src/components/CostCalculator.jsx`**: Dynamic setup feasibility simulator modeling Direct Captive vs. BOT vs. EOR vs. Flexiple Launchpad with CapEx, OpEx, and 3-Year TCO comparisons vs. US/EU onshore benchmarks.
* **`src/components/PartnerEcosystem.jsx`**: Vetted provider network with review ratings and 1-click RFP routing.
* **`src/components/TalentBenchmark.jsx`**: Granular CTC compensation bands and time-to-hire comparisons.
